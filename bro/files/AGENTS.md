# File reading

## Linux confinement

`confinement/` applies irreversible worker-side kernel restrictions after the provider has preloaded its modules, codecs and native libraries.
`SandboxLimits` owns the worker's bounds.
Call `arm_parent_death(parent_pid, limits)` before relocating the reply descriptor, then `apply(limits)` after descriptor setup; the latter returns a `SandboxReport`.
The worker and parent both call `validate_report` to require `REQUIRED_PROTECTIONS` and the protections of the reported ABI.
An unavailable backend or missing protection fails closed.

`SUPPORTED_ARCHITECTURES` selects the native Linux architectures accepted by `uname`.
Emulated architectures are unsupported.
The backend implements Landlock ABIs up to `MAXIMUM_LANDLOCK_ABI`, using that ceiling on newer kernels; only the test helper can lower the ABI in use.
Landlock has no allow rules, and seccomp kills denied calls, foreign audit architectures and x32 numbers, returning ENOSYS for numbers absent from the pinned tables.
On kernels that exempt x86_64 probe trampolines from seccomp filtering, a direct caller outside its trampoline receives SIGILL for `uretprobe` or ENXIO for `uprobe` instead of SIGSYS.

`classification.py` classifies every pinned syscall and lists denied names absent on each architecture.
`tables.py` is generated by `syscall-tables` in `local/` and carries the kernel tag and source hashes.
Offline classification tests belong to `unit`; fresh-process escape tests belong to the gate's `sandbox` roster (`local/AGENTS.md`).


Post-setup resource-limit mutations are denied even for a worker retaining `CAP_SYS_RESOURCE`:
`setrlimit` is denied, and `prlimit64` permits only self queries with a null new-limit pointer.
The filter also denies `fcntl` ownership, signal, lease and notification commands, setting `O_ASYNC`, and signal-producing or redirecting `ioctl` commands.
`F_SETPIPE_SZ` is denied because pipe storage can retain pages outside address-space accounting.
Ordinary descriptor flags and queries remain available.
Post-setup `prctl` cannot reset parent-death or dumpability settings, or mutate core-scheduling cookies; queries and worker-local operations remain available.

## Access

`access.py` defines the `FileAccess` protocol, `FileAccessDenied` and the regular-file opener `AllowAll`.
Callers obtain the active implementation through `current()`;
`installed(access)` scopes an override to the current context and restores it on exit.

`open_read` and `open_write` return binary streams owned by the caller.
`open_write(create_parents=True)` permits parent-directory creation after the access decision.
`search_directory` returns the authorized search path, which can differ from the requested spelling.
The default implementation imposes no path policy.

On platforms with `O_PATH`, existing files are pinned and checked before reopening through `/proc/self/fd`.
Otherwise the opener checks file identity before and after opening.
Neither path truncates before checking the opened file, and missing write targets are created exclusively.

## Types and results

- `types.py` — frozen `FileType`, `Signature`, `View` and `Limits` declarations, exported from `bro.files`.
  Declarations import models, never parsers; provider imports belong to workers.
- `registry.py` — `bro.file_types` metadata discovery, single-entry loading and `TypeRegistry` caching.
  `identify(head)` loads every type, while `resolve(head, type=...)` selects only the explicit type.
- `pages.py` — `parse_pages` checks syntax and the type bound before expansion;
  `select_pages` resolves the parsed selection against the document count.
  Selections are one-based sorted sets; `None` means all pages.
- `text.py` — `sanitize` strips invisible characters and reports printable tag payloads with input offsets;
  `sanitize_strings` and `validate_strings` traverse JSON objects, including keys.
- `models.py` — `InfoResult` and `ViewResult` core envelopes.
  Their `from_validated` constructors preserve the serialized dictionary validated by the runner.
- `operations.py` — async `info` and `view`, synchronous `read_reference`, and manual field coverage validation.
  `Operations` owns the call lifecycle and closes active workers with its tool server.
- `snapshots.py` — bounded, hashed reads through the seam in a daemon thread.
  A cancelled or timed-out read retains its slot until its thread returns.
- `mcp.py` — the registered `file` toolset: `info`, `view` and `read_reference`.

Shared caller rules are in `reference.md`; a type ships its own manual.

The type and result tests run in the gate's `unit` stage without a worker or a parser installation.
File-type authors start at `bro/reference/extending.md`, "Adding a file type".

## Provider protocol and runner

`protocol.py` defines `Provider`, `InvalidInput`, `Job`, `Reply` and the bounded JSON frame reader.
A provider spec resolves to an object, not a factory.
Its `prepare` returns an engine version after preloading and warming the parser;
`info` and `view` receive only snapshot bytes, arguments and type limits.
`InvalidInput` messages contain fixed phrases and counts, never document text.

`worker.py` is the isolated module entry point.
Its argv contains the provider spec, parent pid, sandbox bounds and type limits.
Stdin carries a request frame followed by the snapshot;
the private reply descriptor carries one success or error frame.
Engine writes to fd 1 go to stderr after preparation.

`runner.py` implements the one-method `Runner` interface with `SubprocessRunner`.
It spawns on the awaiting thread, multiplexes nonblocking pipes and a pidfd on that thread's event loop, and kills the process group before reaping the leader.
`close()` prevents new calls and kills active workers;
their awaiting calls own reaping.
A reply requires a zero exit, exactly one frame, valid strings, a complete sandbox report and the type's declared payload model.

`slots.py` owns lazy, thread-safe `WorkerSlots` admission, separate from the runner so callers can acquire before reading.
The default pool is shared process-wide, across operations states and event loops.
Use the acquired `SlotLease` as a context manager for ordinary exits.
For an abandoned read, `transfer()` moves release responsibility to that read's thread;
its `release()` is thread-safe and idempotent.
Protocol and admission tests run in `unit`, while real-worker tests run in `sandbox`.
